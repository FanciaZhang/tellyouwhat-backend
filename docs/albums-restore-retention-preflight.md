# 共享恢复的备份保留期前置检查

2026-11-05。共享备份恢复原先在配置包校验之后才判断 14 天保留期；配置包校验已经会解密文件并执行相册的隔离 SQL 演练。云端取回入口也会在验证清单后继续下载两个大文件，最后才由恢复入口拒绝过期备份。

本次把既有保留期判断提前：

- 本地恢复在备份认证和内容摘要核对后、进入各 App 恢复前拒绝过期包。
- COS 取回在清单认证、范围与字段核对后，先检查保留期，再下载数据库和配置包。
- 保留期仍为 14 天，恰好到期即拒绝；仍在保留期内的最后一秒允许继续原有校验。没有删除输入、缩短保留期或改变恢复格式。

新增检查在修复前复现三个失败：本地过期包仍进入 App 恢复，两个过期云端样本仍下载完整数据。修复后，备份、异地传输、恢复工作区及相册恢复四个模块的 68 项测试通过，无跳过；包含到期边界、有效包、损坏内容、失败、取消及清理保护。测试使用合成文件和 MemoryCOS，验证真实清单认证及下载实现的调用顺序；不代表真实 COS 或本次实际 SQL 恢复演练。
