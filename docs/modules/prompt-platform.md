# Prompt、参数与写作风格

## 管理入口

AI 管理首页提供健康系统提示词，以及手记智能整理、语音整理、写作风格、语音调试、效果评测入口。健康按八个功能独立发布附加 System Prompt；手记的通用 Prompt、Lite/Pro 路由、请求参数、语音识别参数和风格目录作为一个配置集合发布。

编辑内容暂存在当前浏览器会话，输入时保持节点和中文输入状态。草稿支持差异预览、并发冲突合并和历史内容恢复；恢复生成新版本。发布需要通行密钥确认、有效预览和幂等提交。模型从火山目录核对账号可用状态、版本、任务类型和价格，实际参数及结构化响应能力通过生产评测验证。

“去除口头重复”是整理 Prompt 规则。自动标点与数字规范化是语音识别连接参数。后台不提供供应商 URL、凭据或任意供应商请求 JSON 编辑功能。

## 运行与目录

配置版本保存在 MySQL。Gateway、Worker、Admin 启动时加载全部已发布配置，每六十秒刷新内存快照；请求不逐次查询配置表或 Redis。同实例的并发刷新合并，刷新失败保留有效快照，首次加载失败不启动服务。

健康在独立 `instructions` 字段附加 System Prompt，不改写 App 请求、媒体和响应协议。异步任务入队时把配置版本与正文一同加密冻结。手记整理开始时冻结版本，Lite 到 Pro 重试沿用同一配置；语音识别在连接建立时固定参数。预算按组装后的实际 Prompt 和输出上限预留。

`GET /v1/journal/writing-styles` 返回版本、默认风格与公共元数据，支持 ETag/304，不返回 Prompt、供应商参数或凭据。稳定风格 ID 不允许从目录删除；停用后不能新选，已选风格仍可使用。目录更新不重写正文或重置设置。

手记 App 使用持久目录缓存与字符串 ID。首次离线使用内置五种风格；正式版冷启动检查间隔二十四小时，开发版和 TestFlight 为六十秒。失败也记录检查时间，保留缓存；测试渠道与购买状态独立。

## 评测与发布

评测样例来自固定合成内容或管理员明确保存的正文、编辑上下文及音频。内置 PCM 音频为本机语音合成的“今天下午，我和小林在河边散步，后来买了一杯热茶”，单声道、16 kHz、16 位、约五点五秒。

开始前冻结样例、候选配置、模型、参数、评分规则与预算上限，提供生产请求预览。音频识别完成后补入文本，最终请求随结果保存。默认对比当前发布版与选定草稿；独立模型对比使用单独的版本标识，不能替原草稿通过发布校验。

每批最多二十个样例、两个候选、每项一次。持久队列在所有实例间最多并发两个样例，支持取消和逐项结果。重启继续未开始的任务；失去租约的进行中调用标记为中断，不自动重复供应商调用。任务幂等记录与原文遵循七天保留期。

调用复用生产请求组装、解析、引用检查与段落应用。结构、媒体、手改顺序与管理员的内容断言分别检查。原草稿最新评测必须包含 Lite、Pro、语音三种路径，并通过全部候选协议检查后才能发布。

AI 评分使用当前发布版的 Pro 模型，记录实际模型、匿名排列、评分请求与规则版本，按事实忠实度、内容保留、编辑意图和风格符合度评分。格式失败时加密保留模型输出供管理员查看，界面按纯文本呈现，不执行其中的内容。评分失败显示未完成，不作为协议通过证据；AI 分数不决定发布。

评测预留计入同一项目预算，逐次调用使用原有费用结算和并发控制。未使用预留在结束、取消或恢复时释放。管理评测不扣用户权益，不进入用户转化或生产错误率自动保护统计。

手工样例、运行原文和结果使用服务端 AES-GCM 加密，七天后由 Worker 或维护任务清理。配置、审计和无原文的预算持有信息进入管理备份；原文与结果不进入备份。恢复后自动释放孤立预算持有记录。

## 验收操作

浏览器检查脚本为 `scripts/prompt-admin-ui-test.mjs` 与 `scripts/prompt-evaluation-ui-test.mjs`，覆盖真实 CSP、逐字输入、光标、中文组合输入、手机深浅色、结果切换和取消。

真实模型验收可以从后台启动内置样例。服务运维还可在有数据库和火山服务身份的运行环境执行：

```sh
/service synthetic-evaluation preview [sample-ids]
/service synthetic-evaluation start <preview-digest> <idempotency-uuid> [sample-ids]
/service synthetic-evaluation status <run-uuid>
```

上述命令属于 `adminctl`，只使用内置合成样例，不发布配置或更改模型 Endpoint。预览不调用推理；开始执行时预留预算，任务与费用在管理后台可追溯。同一开始请求重试必须复用幂等 UUID。

`sample-ids` 为可选的逗号分隔内置样例 ID，用于只复测相关样例；不传时运行完整发布必测集合。额外内置样例按每批最多二十项选择。

## 语音调试工作台

入口为 AI 管理 → 手记 · 语音调试。指派了 Journal 的运营人员可直接进入；服务端只允许访问本人调试样本、草稿和运行记录，不能发布配置、管理模型 Endpoint 或处理其他 App。管理员保留原有完整评测和发布权限。调试使用 CSRF、原有写开关、可信模型白名单和服务器单价；客户端价格不可信。

### 操作顺序与本机草稿

录音或上传 → 转写音频 → 校对原文 → 修改整理规则 → 整理成稿。只调成稿也可以直接粘贴文字。模型名称可读，参数、风格提示词和技术请求折叠显示。成稿可命名、保留、选择对照、标出文字差异、复制和导出；原文不同的版本会提示不能直接比较。可从服务器运行记录把原文和规则载入新样本，无需重复调用模型。仅管理员可转入发布管理，沿用冲突合并、完整评测和通行密钥确认。

IndexedDB 按登录用户保存原音频、手动校对文本、规则、结果及任务标识；同源同一浏览器刷新后可以恢复。上传新音频会新建样本，避免套用上个录音的文字。删除本机样本必须明确确认，不按七天自动删除，也不删除服务器记录。离开工作台会结束并保存录音、关闭麦克风；关闭标签页前提示未完成保存。录音逐片保留，异常退出后可恢复，编码不完整而无法解码时仍提供原片段导出。大写入前检查空间；保存失败或另一标签页已修改时保留内存输入并提示，不能静默覆盖。只清理本作者命名空间内已不再被样本引用的录音片段。浏览器清理站点数据、不同浏览器或不同后台域名不会共享本机样本。

### 两种转写

浏览器支持 M4A、MP3、WAV 等可解码音频，最多 80 MB、30 分钟；先转成单声道 16 kHz PCM16，点击预览后上传加密样本，确认费用后才发起真实调用。

- **口述转写**沿用 App 的流式 ASR、热词、标点及数字规范化设置；以最多 15 秒的片段、每批最多 20 项运行，并发仍受全局限制。它复现识别质量，不模拟实时收音时序或弱网切换。失败段独立保留，修改热词仍可只重试失败段，不覆盖已有校对文本。
- **录音文件转写**沿用手机导入录音的整段 `RecordingASR`、标准 AUC 资源、说话人和情绪参数，保留整段上下文；原始结构化结果可检查说话人及时间。一个录音只提交一个 ASR 任务。调试成稿仍为单人叙述，不包含 App 的多说话人确认、富文本、照片或手动编辑冲突流程。

整段录音由服务器依据本人持有的分片计算长度与 SHA-256，并在启动事务中复制到按运行归属的加密有界行；删除原样本不能破坏已开始任务。Worker 逐片解密、流式上传，不创建临时 PCM/WAV 文件。供应商任务 ID 在发出请求前持久化；响应丢失或工作进程中断后，“核对原转写”只查询该 ID，不自动重复提交音频。费用不明确的调用保留预算预留。录音输入随运行七天到期级联清理。

### 成稿与费用

最终成稿使用 `voice.PrepareRewrite` / `ArkRewriter` 的 `PolishRequest` 路径和同一响应校验，按有界文本窗口与前文组织段落。`journal.voice.polishPrompt` 为最终成稿的附加要求，空值沿用默认规则；它与风格 Prompt 进入同一个真实请求。轻量纠错、语音编辑仍使用原有规则。结果可展开实际请求、模型、token、耗时、成本估算、原始失败输出与校验阶段。

快速试跑采用 `mode=voice_debug`，每项一个候选，不额外调用 AI 评分，也不能代替发布必测的 14 项完整评测。费用预览过期时须重新预览并确认，不直接重发旧请求。开始请求复用幂等键；`GET /api/v1/ai/evaluations/commands/{command}` 仅查询当前账号原提交。切换、取消或新建任务后，旧响应不能覆盖新任务的状态。

上线需成套升级 Admin 与 Worker，并应用 `0085_prompt_voice_debug_samples.sql` 和 `0086_prompt_recording_inputs.sql`；不能只替换静态页面。0086 只添加调试录音输入表，不改动 App 用户数据，已加入测试部署的精确迁移哈希白名单。调试样本不会挤占发布样本库的 200 条列表。旧 Worker 不认领快速任务的待执行状态；回滚不自动重试付费调用。

### 定向验收

`scripts/voice-lab-ui-test.mjs` 用实际浏览器、原生 IndexedDB 和 MediaRecorder 检查解码、麦克风释放、草稿恢复、跨标签页冲突、空间不足、录音片段清理、原文保护、失败段重试、过期预览、幂等恢复、取消及深浅色布局；服务响应为可重复夹具。`scripts/prompt-evaluation-ui-test.mjs` 检查共享评测页面回归。

`TestLiveVoiceDebug` 为原有真实分段识别/成稿检查；`TestLiveVoiceDebugBrowser` 经实际认证会话和 Admin HTTP 处理器运行“上传合成录音 → 整段识别 → 整理成稿 → 浏览器应用 → 刷新恢复”。后者仅在 `JOURNAL_VOICE_DEBUG_LIVE_EXECUTE=1` 且提供私有配置、明确剩余费用上限、独立 MySQL 测试数据库和绝对证据路径时执行，测试账户只存在于临时数据库。局部测试 TLS 来源映射只在测试文件中，不改变生产认证。私有配置不进入源码或证据。

```sh
# DSN 必须指向明确以 _test 结尾的可丢弃数据库；费用上限使用 nanos。
MYSQL_TEST_ADMIN_DSN='<private test DSN>' \
JOURNAL_VOICE_DEBUG_LIVE_CONFIG='<private configuration JSON>' \
JOURNAL_VOICE_DEBUG_LIVE_EXECUTE=1 \
JOURNAL_VOICE_DEBUG_MAX_NANOS='<explicit remaining nanos>' \
JOURNAL_VOICE_DEBUG_EVIDENCE_DIR='<absolute evidence directory>' \
PLAYWRIGHT_MODULE='<installed playwright module>' \
go test ./internal/adminportal -run '^TestLiveVoiceDebugBrowser$' -count=1 -timeout=7m
```

私有配置 JSON 使用 `JOURNAL_VOICE_ASR_API_KEY`（或已有 AppKey/AccessKey）、`JOURNAL_ARK_BASE_URL`、`JOURNAL_ARK_API_KEY`、`JOURNAL_ARK_LITE_MODEL_ID`、`JOURNAL_ARK_PRO_MODEL_ID` 及可选 `JOURNAL_VOICE_MODEL_ID`。真实测试只使用仓库自带合成音频；不得把用户录音变为夹具。费用预览、实际供应商通过、浏览器正确应用和用户验收分别记录。
