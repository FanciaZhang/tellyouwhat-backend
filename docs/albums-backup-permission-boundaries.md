# 相册测试备份权限边界

2026-11-05，使用两套已授权的相册测试身份，完成 24 项真实 COS 拒绝检查，全部得到 `403 AccessDenied`。包括原有 16 项及新增 8 项跨桶读取/版本查询检查；只使用本次随机合成键，未变更云权限或读取用户媒体。

| 身份 | 验证被拒绝的操作 |
| --- | --- |
| 写入身份 | 删除固定版本、创建删除标记、普通 PUT、终止活动分片、读取其他前缀、读取桶 ACL、列举其他前缀版本 |
| 清理身份 | 普通 PUT、初始化/上传/完成分片、创建删除标记、删除 `null` 版本、读取其他前缀、读取桶 ACL、列举其他前缀版本 |

写入身份先分片上传并固定版本回读合成字节，另创建一个活动分片会话。拒绝检查之后再次核验初始版本未变，再由清理身份删除本次版本和分片；回执同时确认版本、分片清单为空。

新增检查分别以写入和清理身份请求相册测试媒体桶 `tellyouwhat-albums-1251995834`、正式媒体桶 `tellyouwhat-albums-production-1251995834`：读取本轮随机键、查询该键前缀的版本（最多一条），均要求 `403 AccessDenied`，网络错误、404 或其他错误不算通过。跨桶只发只读请求，不创建、上传或删除对象；版本响应不记录用户对象清单。本次没有用其他身份确认这两个桶的存在状态，也不把结果扩大到其他桶或操作。[跨桶实测证据](evidence/albums-backup-crossbucket-2026-11-05.json)。

## 执行与恢复

```sh
ALBUM_BACKUP_PERMISSION_PROBE_DIR=/absolute/private/directory \
go test -tags albums_live ./cmd/albumbackup \
  -run '^TestLiveBackupPermissionBoundaries$' -count=1 -v
```

目录要求 0700，内部 `probe.json` 要求 0600：

```json
{"scope":"albums-backup-permission-probe-v1","writer":"/private/backup-writer-cos.json","cleanup":"/private/backup-expiry-cos.json"}
```

入口固定广州测试备份桶，拒绝同一身份或不同目标。未显式提供目录时跳过，不进入普通 CI 的云请求。它是独立存储权限检查，不依赖模拟 App 订阅。

创建云资源前保存带 HMAC 的随机键意图，每次初始化后保存会话；独占租约防止另一个进程回收活跃测试。只清理这两个合成键及内容摘要匹配的版本，数据字节直接来自内存。已有意图的目录只做恢复清理，并以非零状态说明未运行新矩阵；恢复报告独立命名，保留旧结果。凭据变更或意图校验失败时停止并保留记录，不猜测删除范围。
