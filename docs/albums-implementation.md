# 告你相册后端接入

Bundle ID 为 `cn.tellyouwhat.albums`。相册是长期账户媒体业务，不复用 `internal/media` 的 24 小时临时对象，也不以 App Attest 设备 key 作为跨设备账户。

当前 `internal/albums` 实现资源清单和实际读取校验的领域规则，包括实况资源完整性、编辑后显示资源、版本绑定、大小与哈希核对。尚未挂载 HTTP 路由，未连接 COS/CI，不能作为已上线备份服务。

后续接入必须完成：稳定账户认证、AlbumAPI 生成合约、App 注册和 Host 隔离、事务额度预占与持久任务、COS 私有对象直传、独立原件校验任务、CI 派生处理、同步游标与删除标记、原件恢复、授权分享、回收站和长期索引备份。现有 App 注册器包含 Managed AI 特定假设，相册接入时要先拆开存储权益与 AI 操作要求，不能伪造 AI 产品 ID 绕过校验。

本工作树基于 `origin/main` 独立创建，未修改原主目录的用户变更。所有权限与资源校验必须通过后才允许发布备份确认；客户端声明的 SHA 元数据不是校验证据。
