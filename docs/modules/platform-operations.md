# 费用、额度与运行管理

管理后台提供费用总览、额度设置、运行状态和配置记录。所有统计按 App 隔离展示，只有管理员可修改平台策略；运营人员沿用已有 App 授权范围，不获得平台管理权限。

## 费用与额度

平台策略管理项目及各 App 月预算、项目并发、预算提醒比例、订阅日/月 token 额度、健康免费识别次数及安全 token 上限、手记每订阅周期语音额度。预算周期使用 UTC 自然月；语音周期继续锚定已验证的订阅日期。单次语音最长 30 分钟仍为协议边界。

费用由供应商用量乘计价上限估算，分为已结算、处理中预留、结果待核对。结果未知时保留预留金额；不将该值表示为供应商账单。降低预算或额度不会清空既有消费与预留；低于已用量时阻止新的预留，已有调用仍正常结算。

服务配置写操作由独立的 `PLATFORM_OPERATIONS_WRITES_ENABLED` 开关控制，默认关闭，不受 Offer 写开关影响。GitHub production 环境中同名变量可覆盖部署文件中的值。

## 发布与恢复

首次启动从现有部署配置初始化完整策略，后续重启或发布不覆盖数据库中已发布的版本。变更经过草稿、差异预览、通行密钥确认和事务发布。预览绑定管理员、版本、策略摘要与有效期；过期预览、重复提交和并发修改均验证。恢复历史版本创建新的草稿，不重写历史。回退至不支持平台策略的旧服务镜像前，先将预算与额度恢复为该镜像的部署默认值，并确认配置状态；旧镜像不会读取数据库策略。

预算发布与费用预留使用相同数据库锁。服务每次接单读取当前策略，读取失败时拒绝新请求；既有费用、配额预留和结算窗口不因策略变化而重建。

## 暂停与运行状态

可暂停整个 App 或指定功能。暂停阻止新的业务请求；尚未领取的健康异步任务等待恢复，不消耗模型重试次数，仍遵守原有 24 小时有效期。已领取的任务、已发出的模型调用及已建立的语音连接继续完成。恢复不会绕过权益、配额、有效期和模型兼容检查，也不改变火山原生灰度。

运行页面显示最近 24 小时的调用结果、token、耗时和队列状态，并按配置的预算比例、错误率和延迟阈值显示后台告警。错误率只基于已观测的终态调用，历史未采集数据不作为成功；样本量不足时显示样本不足。统计不包含正文、Prompt、媒体、设备或交易标识。拦截汇总保留 31 天，幂等提交结果保留 400 天；已发布策略和历史版本进入管理数据备份。

## 验证

验证包括真实 MySQL 的预算并发、调额与结算、版本冲突及审计事务，真实 Redis 的额度变更与原窗口结算，暂停与恢复的入口和任务路径，以及带生产 CSP 的手机宽度浏览器交互。
