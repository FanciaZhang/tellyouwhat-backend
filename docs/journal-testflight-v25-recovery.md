# TestFlight 1.0 (2) 语音修复 — 2026-10-04

已更新独立开发服务，并通过 App 的合成录音在线验收。现有录音可直接重试，无需发布新的 App 构建。

## 原因与修复

- App 构建源码 `18ddf0389a14859a3f12a6c2158af0f1e2c070c4` 要求 `journal-voice-v25`，原开发服务二进制仍为 v20。此前只检查了 `subscription-v2` 和就绪接口，漏查语音协议。
- 将已实现的 v21–v25 语音字段、模型 Schema、上下文投影和授权校验整合到现有独立开发运行时，保留原来的录音恢复及费用历史能力。
- 实际联调进一步复现口述自我纠正的来源分类错误：模型将“不是小明，是小林”标成无目标的 correction 分区。补充明确指令：新口述中未进入正文的旧称呼与改口说明使用 context，更正后的实际内容使用 content；correction 仍必须引用真实旧正文修改目标。校验未放宽，并增加正确／错误模型响应的回归测试。
- 开发服务同时报告连接与语音版本。连接脚本在替换服务前核对选定后端源码，在连接后核对实际线上语音版本，阻止只更新 App 或选错后端检出后继续报告成功。
