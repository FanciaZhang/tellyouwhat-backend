# 无密码管理后台

## 安全边界

共享管理后台只支持 WebAuthn 可发现通行密钥，不提供密码、邮箱验证码、
短信验证码、TOTP 或长期恢复码入口。`ADMIN_RP_ID` 与 `ADMIN_ORIGIN` 固定
绑定同一个 HTTPS 管理域名，不允许通过环境变量降级安全 Cookie。

登录时不先输入用户名。浏览器和系统负责展示本机 Face ID、Touch ID、硬件
安全密钥或附近设备选项；用 iPhone 扫码使用的是系统标准跨设备通行密钥流程，
后台不自行实现二维码身份验证协议。

服务器只保存通行密钥公钥、随机用户 Handle、角色和 App 范围。生物特征和
通行密钥私钥始终留在用户设备或其选择的凭证同步服务中。

## 角色和权限

- `admin`（管理员）：可进入所有已配置 App，管理 Offer，邀请或停用后台人员，
  调整角色与 App 范围，为其他人签发恢复邀请，并查看完整审计记录。
- `operator`（运营）：只能进入 `admin_user_apps` 中明确分配的 App，可查看
  匿名汇总数据并管理 Offer 和码池；不能管理人员或全局 AI 配置，只能看到
  自己的审计记录。

权限由 Go 代码中的固定类型常量维护，暂不提供数据库驱动的细粒度权限编辑器。
前端隐藏入口只是交互层；每个 API 都会在服务端重新校验角色和 App 范围。

管理 API 的路径、方法、参数和请求结构以
`Contracts/HTTP/AdminAPI/openapi.yaml` 为唯一来源。`oapi-codegen` 生成 Gin
Router，认证与 Offer 业务直接实现生成的 Gin 接口；不再存在手写
`http.ServeMux` 或把旧 `net/http` Handler 包进 Gin 的兼容层。

无论哪种角色，都不能通过管理后台读取手记正文、健康数据、原始 AI 请求、
部署凭证、大模型供应商密钥或 App Store Connect 私钥。

## 首次设置、邀请与恢复

首次运行时，在服务器环境执行：

```sh
go run ./cmd/adminctl bootstrap
```

命令只输出一次性设置链接，15 分钟后过期。初始化完成后，管理员在网页端邀请
其他人。邀请 Token 在数据库中只保存 SHA-256 摘要，原文位于 URL fragment，
不会作为 HTTP 路径或查询参数发送给服务器。链接只能成功接受一次，角色和
App 范围以服务端邀请记录为准。

每位管理员建议至少登记两枚通行密钥：一枚可同步通行密钥，加一枚独立
FIDO2 硬件安全密钥。

运营人员或其他管理员丢失全部凭证时，另一名管理员再次验证自己的通行密钥后
签发恢复邀请。签发动作会立即删除目标账号的旧 Passkey 公钥并提升会话版本；
旧 Passkey 与所有旧会话从此失效。当前账号不能为自己签发网页恢复邀请。

最后一名管理员丢失所有凭证时，需要有数据库和服务器环境访问权的人执行：

```sh
go run ./cmd/adminctl users
go run ./cmd/adminctl recover <user-id>
```

该恢复通道不暴露为公网 API。`adminctl` 签发的首次设置和恢复动作也会记入
审计表。如果审计写入失败，命令会明确说明已输出的一次性链接仍然有效。

## 会话和写操作安全

- Cookie 固定为 `Secure` + `HttpOnly` + `SameSite=Strict` + `__Host-` 前缀。
- 会话绝对有效期为 12 小时，连续空闲 30 分钟后失效。
- WebAuthn 和邀请登记仪式使用 Redis 中一次性状态，仪式有效期为 5 分钟。
- 每个已授权请求都从 MySQL 重读角色、状态、App 范围和会话版本。停用人员或
  更改角色/App 范围后，旧会话下一次请求立即失效。
- 敏感操作同时要求精确的 `Origin`、CSRF Token、必要时的幂等键，以及 5 分钟内
  完成的 Passkey 再次验证。
- 最后一名启用中的管理员不能被停用或降级为运营。
- 自助界面不能删除账号的最后一枚 Passkey。
- 权限拒绝、安全变更和业务写操作会写入审计记录，但不记录凭证材料、
  邀请 Token、Offer Code、用户内容或原始 AI 输入。

## 开发数据库

项目尚未发布，干净的 RBAC/Passkey 模型直接定义在 `0001_initial.sql` 中，没有
为旧的单管理员表结构保留兼容层。如果开发数据库已记录过旧版 `0001_initial.sql`，
必须在明确确认无需保留数据后手动重建开发库。迁移器不会静默删除或改写旧数据。
