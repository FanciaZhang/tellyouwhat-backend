# 运营数据口径

费用、用量、转化分别保留来源和缺失状态。后台只返回聚合结果，不返回设备标识、Apple 交易标识、请求内容或凭证。

## 费用与调用

- 火山账单：服务账号查询费用中心产品账单，展示账号范围、账期、币种和读取时间。账号账单无法按 App 或订阅类别直接分摊，不能与项目统计混合相加。
- 调用费用估算：供应商返回用量乘服务端计价上限，包含重试。价格取各档最高值，未包含所有工具单独收费、折扣、赠金或资源包抵扣；不能替代账单。
- 预算占用：已估算费用、处理中预留、待核对预留之和，用于请求准入。
- Token：记录供应商返回的输入、输出 token；未返回用量单列，不能以预留 token 替代。语音识别按时长计费，其 token 用量不适用。
- 权益分类：免费、Apple 非零价格订阅、零价格订阅、价格未确认订阅和未知。记录调用执行时的服务端授权与已验证交易元数据，历史记录不按当前订阅身份回填。
- 环境：订阅使用已验证 Apple 环境；免费请求使用 App Attest 环境。免费路径不能完全区分 TestFlight 与正式安装，不作为纯正式用户人数。
- 运行状态：服务端调用终态、耗时、队列与拦截记录；云端开启表示配置允许请求，不表示火山实时健康检查成功。

## 免费体验到付费

以生产 App Attest 身份首次被记录的成功免费请求形成设备观察组。设备身份不是自然人，同一人换机或重装可能形成不同身份。按最后 90 天观察组分别计算 7 天、30 天窗口，只将观察期完整的设备纳入分母；观察中的设备单列。

付费证据来自 Apple 已验证且非零价格的生产交易，购买日期需在首次免费体验之后和观察窗口内，原始订阅日期也必须不早于首次免费体验。试用、零价格兑换、Sandbox、开发授权、已撤销交易、免费体验之前的订阅恢复均不算新增付费。多台设备恢复同一原始订阅，只归因给最早符合条件的免费设备。

金额缺失、历史交易或跨设备未关联会使转化无法完整观测。展示“已验证转化率”，明确不是完整支付平台转化率，更不是自然人转化率。无成熟观察组时显示观察中，不显示 0%。Apple 价格为交易价格，不是开发者收入或实际到账。

新采集的起点由迁移持久化。用户删除清理观察组及交易观察，灾备不恢复这些身份关联数据。身份无关的费用分类与采集起点允许恢复。

## 账单授权

服务继续使用仅挂载在 admin 容器的独立 IAM 凭证，不依赖个人 CLI 会话。
[账单只读策略](../../config/iam/operations-billing-read.json) 只允许
`billing:ListBillOverviewByProd` 与 `billing:ListBillDetail`，账号范围 Resource 为 `*`。
当前页面使用产品账单概览，不调用支付、充值、退款或购买接口。账号级权限可以读取其他项目的产品账单，因此页面明确显示账号范围。

账单在管理服务中按小时缓存，失败后每分钟重试；本地运营统计不等待火山接口。失败保留上次读取时间并标记过期，跨账期清空旧金额等待新账单。只有完整分页、有效币种与完整金额字段才能发布快照；供应商 HTTP 200 中的 API 错误同样视为失败。
