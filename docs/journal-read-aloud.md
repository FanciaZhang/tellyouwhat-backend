# Journal 全文朗读服务

2026-10-21，实施中。产品与 App 验收基线在 JournalApp 仓库的 `docs/read-aloud-product-plan.md`。本文分别记录供应商开通、后端配置与部署、App 联调及听音验收，不由单层成功推定全部完成。

## 已有基础

- `internal/journal/readaloud/provider.go`：豆包语音合成 2.0 HTTP 单向流，固定公共音色资源、24 kHz 单声道 PCM、单请求文本和音频边界。检查终止帧，取消和消费者失败不自动重试，重定向不转发密钥，错误不携带供应商原始响应正文。
- `catalog.go`：公共目录只输出展示及能力信息；启用音色需要标准计费类别和能力探测证据。每种声明语言、风格、方言和音调边界都要经过合成检查。新增能力使旧证据失效，空目录、重复 ID 或无效默认声音不能发布。
- `metered.go`：合成前接入既有项目费用预留，按 Unicode 字符计量；客户端取消仍执行结算。用量不明确时保留预留，费用准入失败不调用供应商。测试默认标准价格为每字符 300,000 CNY nanos，即 3 元／万字符；上线由服务端核对实际计费配置。
- `quota.go` 与迁移 `0068`：持久字符额度及请求指纹。只有首次原子申请取得一次合成资格，重放返回既有状态；不同文字、声音、能力参数或来源版本不能复用请求 ID。正文朗读和固定短句试听拥有独立额度账户，可配置不同周期；额度及周期必须来自可信服务端权益。表内没有正文或私人音频。
- 供应商结果状态和费用确定性分开：音频完整成功但没有实际字符回执时仍可标记成功，同时保留字符预留；后续权威用量只能结算一次。结果未知的请求不会因为进程重建而重新获得合成资格。

## 音色目录与后台

迁移 `0069` 增加不可变目录版本、当前发布指针、能力验证证据和幂等管理操作。草稿不影响 App；发布核对基准版本后原子切换，恢复历史内容会创建新草稿。同步、探测或发布失败保留最后可用目录，成功写操作进入已有管理员审计。历史列表只读取版本摘要，需要恢复时才取单个完整目录。

管理后台的“AI 管理 → 手记 · 朗读音色”提供搜索与语言筛选、官方候选同步、手动添加、展示信息及排序、计费类别、能力、固定短句、示例试听、验证试听、启停、默认声音、差异预览和通行密钥确认发布。同步只添加缺少的 ID，保留已有运营修改；新声音默认未启用且费用待核对。本机草稿按管理员暂存，并发发布后使用字段合并保留本机修改与最新目录。

探测先持久申请，再发起合成；HTTP 结果不明确时使用原幂等键检查，不能自动重新购买一次验证。探测额度由所有管理员共享的每日试听账户控制，同时受现有项目费用预算及并发限制。私人手记不进入后台，验证表不保存音频。

HTTP 契约和生成绑定已更新：

- App：`GET /v1/journal/read-aloud/voices`，公开声音元数据，提供 ETag、304 和四小时缓存指示；不包含密钥、验证正文或运营费用字段。
- 后台：`/api/v1/journal/read-aloud/catalog` 下的当前目录、历史、单版本、草稿、发布、候选同步及能力探测。复用管理员登录、Journal AI 配置权限、同源 CSRF 和审计；发布及探测要求近期通行密钥验证。客户端提交的 verification 或资源覆盖字段直接拒绝。

## 运行配置

未配置密钥时不同步、不调用供应商；单纯启动新程序不会开通服务或购买资源。目录读写与 Ark 管理凭据独立。

| 配置 | 行为 |
| --- | --- |
| `JOURNAL_TTS_WRITES_ENABLED=true` | 显式开放音色管理写操作，默认关闭 |
| `JOURNAL_TTS_INVENTORY_CREDENTIALS_FILE` | 可选私有 JSON 文件，字段为 accessKey 和 secretKey，仅用于官方 ListSpeakers；无环境或默认账号回退 |
| `JOURNAL_TTS_API_KEY_FILE` | 可选私有纯文本合成 API Key 文件；固定官方 HTTPS 接口，不接受客户端替换 |
| `JOURNAL_TTS_PROBE_DAILY_CHARACTERS` | 每日共享验证字符额度，默认 33,333；仍受项目预算限制 |
| `JOURNAL_TTS_ENABLED=true` | 显式启用网关合成会话，默认关闭；仅配置后台验证密钥不会自动启用 App 合成 |
| `JOURNAL_TTS_MONTHLY_CHARACTERS` | 网关启用时必须配置的每订阅周期字符上限；测试值不构成正式订阅承诺 |

| `JOURNAL_READ_ALOUD_SIMULATOR_CREDENTIALS_FILE` | 可选私有测试身份登记文件；仅隔离的手记开发网关可启用，仍需显式启用 TTS、持久存储和费用保护 |

两个凭据文件均需普通文件、无符号链接且组和其他用户不可读，最多 8 KiB；错误不回显凭据。合成文件内容还拒绝控制字符和请求头注入。验证默认单价沿用标准公共 TTS 2.0 的 3 元／万字符，正式启用前核对账号价格。库存凭据和合成凭据不是同一种格式，不能互相替换。

## 云端会话与授权

迁移 `0070` 在保留原有授权的同时增加 `journal_read_aloud`，文档版本为 `2026-10-20`。转写、整理或配图授权不授予朗读权限。首次新合成正文检查独立授权；撤回成功后取消该认证设备的在途会话并清除其服务端音频。隐私资料删除也接入既有清理链，取消各相关设备的会话。

正文额度沿用现有语音功能的原始购买日期月周期；试听使用 UTC 日周期。账户按购买环境与原始交易生成摘要，同一订阅的多个认证设备共用字符账户，重新安装不会创建新额度；各设备的上传授权保持独立。过期订阅可以查询或取消已有请求、读取仍有授权的已生成音频，不能创建新合成。旧 development 权益记录不被当作已验证购买。受限模拟器身份的服务端接入见下文；App 注入、部署及真实豆包联调仍待完成。

## 受限模拟器身份

服务端已接入 `internal/journal/simulatortest`。它只替换显式测试身份的认证与订阅来源；普通设备继续使用 App Attest 和真实 Apple Sandbox / Production 购买。默认关闭，`APP_ENV=production`、其他 App、正式 Bundle ID、其他或多个 Host 都不能启用。固定允许的身份为 `cn.tellyouwhat.journalapp.dev` 和 `api-test.journal.tellyouwhat.cn`。

登记文件是版本为 1 的 JSON，包含 `credentials`。每项保存 `keyID`（`simulator_` 加规范 UUID）、Ed25519 `publicKey`（标准 Base64）、`subjectID`（规范 UUID）、`issuedAt`、`expiresAt`、`revoked`、可空的 `subscriptionStartedAt` / `subscriptionExpiresAt`，以及 `journalCharacters` / `previewCharacters`。不保存私钥、Apple 交易或设备证明。文件及其直接父目录必须私有、无符号链接；文件最多 32 KiB、16 个身份，单个身份有效期不超过 24 小时。每次认证和流授权重读，撤销或文件异常后停止授权。

同一 `subjectID` 的多个测试密钥共享 `simulator:<UUID>` 字符账户，额度和订阅周期必须一致；各密钥的隐私授权独立。订阅日期全空表示未订阅，过去的到期时间表示已到期；测试字符上限由服务端登记，正文最多 100,000、试听最多 10,000，仍受现有项目总费用上限约束。

客户端沿用公开的 App Attest challenge 接口取得绑定 `keyID` 的随机 nonce，但不注册虚构的 Apple 密钥。业务请求显式增加 `X-Tellyouwhat-Authentication: journal-simulator-v1`，其余请求 UUID、Key ID、Nonce、Timestamp、Assertion 头沿用现有名称。Assertion 是以下 UTF-8 文本的 Ed25519 签名，使用标准 Base64 编码；各行之间仅一个换行，末尾没有换行：

```text
journal-simulator-v1
cn.tellyouwhat.journalapp.dev
api-test.journal.tellyouwhat.cn
<keyID>
<RequestBindingDigest>
```

`RequestBindingDigest` 使用既有规范：大写 HTTP 方法、包含原始查询串的请求 URI、请求 UUID、nonce、RFC3339 时间和正文 SHA-256，以换行连接后计算 SHA-256 十六进制摘要。正常 App Attest 的路径绑定不变。签名有效后才原子消费既有 nonce；过期、未知 nonce 和重放被拒绝，未知或重复认证类型不回退普通认证。

只允许朗读会话的创建 / 查询 / 取消 / 有界游标事件、朗读额度及 `POST /v1/privacy/consents`。授权接口额外限制为当前 `journal_read_aloud` 文档，不能借此授权整理、配图或调用其他付费接口。

既有隐私表关联真实 App Attest 密钥。迁移 `0071` 因此增加独立测试授权表，沿用现有隐私服务的版本校验、同意 / 撤回接口和会话停止逻辑；普通隐私数据及其外键不变。网关启用时检查此表，测试身份不写入 `app_attest_keys`、`managed_entitlements` 或普通 `privacy_consents`。测试结束需要撤销身份、取消会话并清理测试资料；迁移仅在隔离数据库实测，尚未应用到运行中的服务。

| 方法与路径 | 行为 |
| --- | --- |
| `POST /v1/journal/read-aloud/syntheses` | 用请求 UUID 创建一次合成；同一身份不能用原 ID 更换文本或参数；JSON 上限 8 KiB |
| `GET /v1/journal/read-aloud/syntheses/{id}` | 查询持久请求状态及短期音频是否还可恢复 |
| `GET /v1/journal/read-aloud/syntheses/{id}/events?after=N` | SSE 读取 PCM16 音频和最终状态；N 为已接收的偶数、排他字节游标，独立于供应商分帧 |
| `DELETE /v1/journal/read-aloud/syntheses/{id}` | 停止在途合成并清除短期音频；重复取消不创建任务或重试供应商 |
| `GET /v1/journal/read-aloud/allowance?purpose=journal` | 查询正文或 preview 的独立字符额度和周期结束时间 |

每次创建均校验当前目录、音色版本和能力；实际付费调用前再次检查授权与启用状态。个性化试听只接受空文本，由服务端选择公开短句，不能通过试听额度上传私人正文。API 不接受供应商密钥、资源标识或客户端自报额度。

服务端只在内存中暂存音频，最多 32 个会话、每订阅 2 个会话及 64 MiB 音频载荷；最多同时处理 64 条音频读取流。合成任务最长一分钟，完成结果保留约 90 秒供断线恢复，未完成缓冲最长三分钟。上游极小或奇数字节分片先合并，客户端只收到完整 PCM16 采样，分帧数量不使内存无界增长。

HTTP 断开结束读取，不取消已经创建的付费任务；重新读取原字节游标不调用供应商。明确停止或撤回才取消任务并释放音频。授权状态暂不可核实时暂停输出，保留原任务；不会将连接取消或数据库故障当成用户撤回。进程重启或缓冲过期后仍保留请求及费用状态，但不重建音频，返回不可恢复信息，由用户明确决定是否创建新请求。
