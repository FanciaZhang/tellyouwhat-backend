# 共享备份版本控制核验

2026-11-05。共享运维 COS 备份传输现在同时核对私有 ACL、从未启用版本控制的状态及完整 `backups/` 前缀的 14 天过期规则。版本状态无法读取、开启、暂停或响应未知时，停止传输。

原有校验只读取 ACL 和生命周期，受控复现确认：启用与暂停版本控制的桶都能通过检查。腾讯云说明版本控制引入历史版本和删除标记，暂停后也不能回到从未启用的初始状态；只检查当前版本过期规则不足以判断历史版本已处理。[版本控制说明](https://intl.cloud.tencent.com/zh/document/product/436/19883)、[版本状态接口](https://intl.cloud.tencent.com/zh/document/product/436/19888)。

本改动适用于共享运维备份桶。相册专用版本化备份沿用独立的固定版本发布和显式清理流程。配置检查通过也不等于已取得物理删除完成的证据。

## 实现与检查

- 复用固定 `cos-python-sdk-v5 1.9.44`。Linux 实测其空 XML 根返回 `VersioningConfiguration: null`；带格式空白或命名空间时返回形式不同。仅接受这些明确的空配置，拒绝隐藏状态、多字段、非空内容及未知形状。
- 34 项共享异地备份和保留恢复回归通过，包含版本状态、读取失败、既有上传读回、文件租约及失败／取消保护。另在服务器内存中用固定 SDK 解析五种 XML 并运行当前校验，结果符合预期；该矩阵未发起云请求、未安装新代码。
- 策略草案仅在原备份桶的元数据权限中增加 `cos:GetBucketVersioning`。对象读写范围保持 `backups/*`，没有新增删除、桶管理或其他桶权限。
- 156 个已跟踪部署输入已归档；只有本轮三个源码／策略文件与原索引不同。复现失败、SDK 空白响应修正前结果、最终日志及来源摘要均保留。

## 当前远端状态

本轮只读核对：测试共享网关镜像标记为 `6ba3f5825eb847993d4230c2de1df68905950ba8`；相册测试 API 的 HTTPS `/readyz` 返回 200。账号数据擦除开关保持关闭。健康状态不代表真实登录、购买或注销完成。

现有运维备份身份调用 `GetBucketVersioning` 返回 403 `AccessDenied`，因此桶的实际版本状态尚未确认。部署本改动前，需先给该身份补齐上述限定桶的只读权限，再复核真实桶状态及备份往返。没有更改云策略、桶配置、当前服务或用户备份。

相册专用备份身份、历史副本最终清理、最新删除检查点证明及完整账号注销仍须分别验收，注销入口继续关闭。本地校验及测试不能代替这些结果。[结构化证据](evidence/shared-backup-versioning-2026-11-05.json)。
